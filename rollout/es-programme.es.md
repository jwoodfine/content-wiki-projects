Se prevé que la cartera de tenencia directa de Woodfine se expanda hacia España como parte del [[rollout-index|programa de implementación]] más amplio. Este artículo describe el programa previsto para España; no es un registro de sitios actuales, plazos comprometidos ni un mapa regional finalizado.

## Alcance previsto

El programa de España tiene como objetivo definir [[development-regions|regiones de desarrollo]] dentro del país — las zonas geográficas y jurisdiccionales dentro de las cuales se evaluarían los candidatos de co-ubicación y se aplicarían las posturas de cumplimiento correspondientes. Estas regiones aún no se han definido formalmente para España; este artículo se actualizará una vez que se definan.

## Seguimiento de sitios a medida que el programa avanza

Los sitios candidatos identificados para España se seguirán a través de la cartera activa de desarrollo y, cuando el suelo adyacente aún no esté disponible, a través del [[about-development-site-monitoring-register|registro de monitoreo de sitios de desarrollo]], a medida que la [[co-location-methodology|metodología de co-localización]] identifique ubicaciones calificadas. Aún no se ha establecido un recuento de desarrollo requerido para un vehículo de tenencia directa en España; este artículo no afirma ninguno, y no debe inferirse a partir de los recuentos ya documentados para otros países.

## Estado

El estado del programa de España es planificado. Este artículo no afirma recuentos de sitios, regiones ni plazos para España más allá de lo indicado aquí, y se ampliará a medida que la estructura regional del programa se establezca formalmente.
